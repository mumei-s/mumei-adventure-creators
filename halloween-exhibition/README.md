# 夜のとびら — Halloween Yearbook

日本語・モバイルファーストの静的な参加者年鑑プロトタイプ。GitHub Pages のサブディレクトリでも動作します。ビルド・ログイン・バックエンド・解析サービスは不要です。

## 現在の展示

ユーザーの仮展示指示に基づく8枠です。無名S noteさんの実際の企画紹介記事1件と、**明示的に架空の参加者7件**で構成されています。確認済みの参加者名簿ではありません。記事は主催者の企画紹介であり、投稿作品とは表記していません。

- 元記事: https://note.com/ss_yr/n/n52be511ec082
- 主催者名・記事タイトル・画像出典: 上記記事（2026-10-13確認）
- 7件の仮参加者には外部の個人情報・作品リンクはありません
- 画像未取得・リンク拒否時はCSSの扉にフォールバックします
- 企画記事画像のみ note の画像サーバーへアクセスします。追跡スクリプト、外部フォント、音声はありません

## ローカル実行

このフォルダで `python3 -m http.server 4173` を実行し、http://localhost:4173 を開きます。JSONをfetchするため、index.htmlをfile://で直接開く方法は対応しません。

`npm test` でデータ検証とURL安全性のテストを実行できます。追加依存はありません。

## データ編集

`data/archive.json` が表示内容です。`schemaVersion` は1。

- `creators`: 年をまたいで変わらない参加者ID (`id`) と `name`。任意で `bio`、仮参加者の場合は `provisional: true`。
- `years`: `year`、`title`、`description`、`entries`。2027年を追加する際は2026年を削除せず、新しい年度オブジェクトを追加します。
- `entries`: `creatorId` 必須。`title`、`message`、`tags`、`theme`、`role`（主催者の記事は `host`）、`image`、`imageAlt`、`works`、`links` は任意。
- `works` / `links`: `{ "title": "作品名", "url": "https://..." }` の配列。
- `theme`: moon / forest / star / ghost / pumpkin / violet / letter。
- `image`: HTTPS URLまたは `assets/...` の相対パス。リンクはHTTPSのみ許可。危険なスキームは表示しません。
- 各年度内で同じ参加者IDを重複登録できません。別年度への再登場は可能です。
- 本番参加者を追加する際は名前・記事・作品・画像の公開許可を確認してください。

表示テキストはDOMのtextContent経由で挿入し、HTMLとして解釈しません。画像エラー時は装飾扉を表示します。年度やタグを選んでも検索文字列は維持されます。タグの選択肢は当該年度のみから生成されます。

`data/demo.json` は空の年鑑で「サンプルを見る」を選択した場合だけ使う別の架空データです。本番と体験用の訪問記録は別々に保存します。`archive.json` の参加者と年別entriesを空にしても、準備中画面が表示されます。

## 独自の館の体験

訪問した参加者の窓に灯りがともる8窓の建築マップと、一覧検索を並存させています。全窓訪問時は館全体が柔らかく光ります。各室は絵描き、魔法店、観測室、喫茶室、衣装室、音楽室、郵便室など異なる独自SVG。未来の棟は参加者・開催予定を捏造しないイメージ表示です。

館のメインビジュアルはこのサイト用に新規生成したオリジナル画像です。参照サイトの画像・コード・文面は使用していません。

## 体験とアクセシビリティ

部屋間の連続閲覧、館の窓点灯、名前・展示タイトル・作品名・タグ検索、タグ絞り込み、絞り込み内ランダム表示、詳細ダイアログ、年度切替、訪問パスポート、星の発見。通常のグリッドはゲームをしなくても全件閲覧できます。訪問順による順位・人気表示はありません。

ネイティブbutton/dialog/select、キーボード操作、Escape閉じ、フォーカス可視化、読み上げラベル、結果件数通知、スキップリンク、動きを減らす設定に対応。ダイアログを閉じると呼び出し元にフォーカスが戻ります。

localStorageが利用できない場合、現在のページ内メモリで継続し、保存できないことをしおり・詳細で説明します。リセット対象は表示中の年度のみです。外部送信はありません。

## GitHub Pagesへの配置

このフォルダ全体を希望の公開ディレクトリに配置します。既存サイトのサブディレクトリ (`halloween-exhibition/` 等) に置く場合も変更不要です。相対URLのみを使っています。公開対象はこの独立ディレクトリのみです。既存のHalloweenツール、INSIGHTのコード・設定・データは変更しません。

注意: 元記事画像は外部ホストに依存します。権利確認済みのローカル画像へ差し替える場合は assets/ に保存し、imageを相対パスに変更できます。
