FROM DRAFT TO EXHIBITION

公開するには、あとひと手間。

「下書きに保存」だけでは展示は変わりません。以下のJSONをGitHubで更新し、Pagesの反映を確認してください。

  1. 下書きをバックアップ

    端末を替えるときや、読み込みの前に保存。

  2. JSONを確認・書き出し

    通常・Halloweenは archive.json、冒険室の書庫は catalog.json。

  3. GitHubで反映

    下の対応するファイルを開き、全文を置き換えて変更を確認・コミット。変更したファイルだけを更新してください。

    通常・Halloween のJSONを編集 ↗halloween-exhibition/preview/data/archive.json書庫のJSONを編集 ↗halloween-exhibition/preview/maze/data/catalog.json
  4. 公開画面を確認

    GitHub Pagesのデプロイ成功後、展示を再読み込み。反映まで時間がかかることがあります。
