# Native Canvas comparison evidence

Generated by ../tools/render-evidence.mjs.

- exploration-comparison.mp4: actual createStageRenderer, 390×420 per version, same directional input and speed ceiling.
- special-move-comparison.mp4: actual battle-scene renderer and shine effect clock.
- castle-cast-comparison.mp4: actual drawCastleCast over the packaged palace image; not browser gate/CSS.
- all-cast-review.mp4: sequential 8-second reviews of 18 cast, 2 fictional residents, 10 monsters. Same source art; four-pose/turn limitations remain visible.
- contacts/: every atlas, direction, walking pose and measured foot anchor.
- measurements.json: source hashes, file sizes, decode estimates and native Canvas CPU timings.

No browser, phone, DOM/CSS, WebGL, audio or device FPS was tested. Offline CJK text uses Noto Sans CJK JP from the official notofonts repository under SIL OFL 1.1; its hash/source are recorded, and the font is not shipped in this runtime. The upper actor in each cast clip has 75-pixel body height, matching the stage renderer scale at 390-pixel width. The lower actor is explicitly a 2× inspection. Source assets are unmodified. To reproduce Japanese text, set EVIDENCE_CJK_FONT to NotoSansCJKjp-Regular.otf from the official source recorded in measurements.json. No interpolation or fabricated intermediate artwork is inserted.

Reproduce from repo root: node --expose-gc halloween-exhibition/preview/work-review/tools/render-evidence.mjs /path/to/baseline-repo

Canvas render milliseconds exclude image decoding and ffmpeg, and are not browser/GPU frame-rate measurements. The complete source pose review is not a claim that all animations pass.
