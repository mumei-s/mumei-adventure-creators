## 再生成

リポジトリ直下で以下を実行する。保存済みアイコンと現在のmanifestだけを読み、ネットワークや本番カウンターは使わない。

```bash
node halloween-exhibition/preview/work-review/evidence/cast-comparison/build-gallery.mjs
```

`@napi-rs/canvas`を含む`CODEX_PRIMARY_RUNTIME_NODE_MODULES`と、Noto CJKを指す`EVIDENCE_CJK_FONT`を使用する。原本のアイコン取得URL・時刻・ハッシュは`icon-provenance.json`、ゲーム画像は`adopted-asset-provenance.json`。
