## 選び方

- **細かく**：作風・画材→世界観・シーン→衣装・主役→ポーズ→表情→アングル→配色→デザイン→文字→サイズの10項目。作者の活動確認はChatGPT側で行い、ツールにタグ・セリフ欄はありません。
- **簡単**：作風・画材→世界観・シーン→デザイン→文字→サイズの5項目。残りは制作ごとに選びます。
- **おまかせ**：サイズを保ち、3つの組み合わせを提案。選んだ項目の組み合わせで制作します。

選択画面の見本は説明用です。生成では項目名と具体的な描画条件を使い、作成者の参照画像から人物や景物の識別要素を保ちます。見本の顔・性別・背景・小道具は生成入力に含めません。

「このツールで添付」は作成者自身の参照画像と `prompt.txt` を共有します。画像は編集後の内容を使い、単一画像では画像バイトをそのまま保存・共有します。複数画像も元の各ファイルを共有でき、別途、参照だけを1枚にまとめて保存できます。ZIPには、ツールへ取り込んだ `reference-` で始まる参照画像、`prompt.txt`、`使い方.txt` を含みます。標準ZIPに別工程の指示は入れません。段階制作は画面の詳細欄から明示的に選ぶ場合だけ使います。選択画面の見本絵は含みません。

「ChatGPTで自分で添付」は、必要な主参照をChatGPTで直接添付して指示と同じメッセージで送ります。ツールへの主参照登録は不要です。宝石光彩の専用画風原画は、ご自身の主参照と別の描画資料として制作セットに含めます。人物なしの風景・モチーフは、参照風景や参照配色を明示していなければ添付なしでも制作できます。共有の可否は端末と共有先アプリによります。画像と指示を受け取れない場合はZIP保存または個別コピーで渡します。
