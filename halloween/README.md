# 無名S note / Halloween Atelier

参加者のキャラ・名前・公開活動を使う制作プロンプトツール。Halloween／普段使いを切り替えてブラウザーで利用できます。画像生成は、参照画像・制作指示をChatGPTに渡して行います。

## 選び方

- **細かく**：全10項目。Halloweenは500の細かな選択肢。元の形式・画風・感情などを維持し、ポーズを独立して指定できます。セリフは「文字・広告・セリフ」の中で選びます。
- **簡単**：形式・画風・テーマ・文字・サイズの5項目。残りは制作ごとに選びます。
- **おまかせ**：サイズを保ち、3つの組み合わせを提案。選んだ作例の組み合わせで制作します。

450点の個別作例と普段使い用の新規12点を選択枠と一覧の余白に表示。「画像＋プロンプト」は、このツールに添付したキャラと作例を `reference-board.jpg` にまとめ、制作指示のテキストと `prompt.txt` を一緒に共有します。「プロンプトのみ」は、ChatGPTで作成者が画像を添付し、コピーした指示と同じメッセージで送ります。この方式では作例画像の添付を必須とせず、各選択の描画仕様をテキストで渡します。作例の顔や固有の作品をコピーする指示は含めません。

画像付き共有とZIP保存は、キャラ画像・作例画像・prompt.txtを含みます。プロンプトの文字だけをコピーした場合は、画像もChatGPTへ添付してください。生成モデルの解釈、文字の再現、希望寸法には限界があり、プロンプトだけで完全一致を保証するものではありません。

## ページの動き

オレンジのHalloweenイラスト背景、ポップリング、選択の光、パネルと画面の登場演出、灯りの切り替え、選択時の反応、制作準備中の表示。演出ON/OFFとOSの動きを減らす設定に対応。スマホ・タブレット・PC表示を切り替えられます。

## 公開・更新

このフォルダーをGitHub Pagesで公開します。`supabase/functions/halloween-profile/` は専用の公開note情報読取APIです。既存アプリのデータベース・認証・通知機能を使用・変更しません。関数はJWT検証を有効にし、公開クライアントには互換用の公開anonキーだけを使用。サービスキー、Googleアカウント名、旧公開URL、元サイトのGit履歴は移転対象に含めません。

APIは固定されたnote.comの公開プロフィールと公開記事一覧をページ単位で読み、読める無料公開記事の本文を参照します。有料・会員限定・非公開の本文は取得しません。画像や入力を保存せず、取得結果は短時間キャッシュします。件数・本文文字数は画面に表示しません。IDは作品には印字しません。名前と活動は手動編集できます。

## VERSION 9（現在の仕様）

- 表示する選択は10項目。セリフを「文字・広告・セリフ」のタブへまとめ、ポーズを独立した項目にしました。文字量とセリフはそれぞれ保持します。
- 立つ・座る・寝る・走る・跳ぶ・浮く・手のしぐさ・道具を使う動きなど48種類のポーズと自由入力。顔の角度・表情と体の動きを別々に指定し、手に持つ物やカメラとの整合を制作指示に反映します。おまかせでは直近のポーズを避けます。
- 作例資料は1440×1920の3列4段。8番はポーズ、9番は文字・セリフ、10番はサイズ。キャラとまとめた資料は2560×1800です。
- 旧履歴はポーズを「おまかせ」として読み込み、以前保存したプロンプトはそのまま閲覧できます。

新規48点のポーズ見本は built-in image_gen によるオリジナルのアトラスをネイティブ解像度で分割しました。制作プロンプトは `pose-artwork-prompts.json`、画像は `pose-001.jpg`〜`pose-048.jpg` に保存しています。

## VERSION 8（継続する仕様）

- 演出と活動反映は独立したON／OFFボタンで現在状態を明示。活動キーワードにもON／OFFを表示し、外した話題は本文由来の案・広告コピーから除外。物語・セリフの提案は解除すると前の選択へ戻ります。
- 画像添付欄は常時表示。写真選択、クリップボード読取、画像の通常貼り付け、ドロップに対応。権限・形式が使えない端末では長押し貼り付け欄と写真選択を案内します。
- 比率指定、ドラッグ、二本指・ホイール・スライダーで画像を編集。切り抜いた画像を制作資料とZIPへ反映し、元画像に戻せます。画像はブラウザー内で編集します。
- 選択画面を開き直す際に、選択済みのページへ復帰。リングでは中央に、一覧では選択済みのカードを表示。左右スワイプ・ドラッグ・矢印キーでもページ移動できます。
- ７種類の魔法、触れる４つの飾り、３種類の装飾。短時間の演出は同時発生を抑え、OFF・省動作・非表示で停止します。
- 普段使いはトップ・背景・飾りを変え、日常・旅・制作のテーマ、普段着、非Halloweenのセリフと広告コピーへ切替。共通の画風・形式・色・サイズを維持。Halloween側の選択も切替前の状態へ戻せます。
- トップには組み合わせの解釈の限界を短い吹き出しで案内し、固定のツール名を大きく表示。特定の参考ジャンルだけを優先する入口はありません。

新規12点は built-in image_gen で生成したオリジナルのアトラスをネイティブ解像度で分割したものです。プロンプトは `everyday-artwork-prompts.json`、画像は `everyday-001.jpg`〜`everyday-012.jpg` に保存しています。

```sh
npm run check
npm run preview
```

公開後の閲覧にWorkは不要です。GitHubでのコード更新や一般の開発環境でも管理できます。


## VERSION 5（更新履歴）：見比べる一覧とIDからの自動入力

選択肢を画面幅・高さに合わせて4〜12枚ずつ並べるページ式の一覧に変更。分類と検索で絞り込めます。細かな416選択肢、366枚の作例は維持しています。

別ページの作例も最大4枚まで比較に追加して横に並べられます。拡大画面では1〜3倍にして細部を確認でき、そこから正確な選択肢を選べます。画風には固有の見比べるポイント（筆跡、透明感、線、紙・素材など）を表示し、同じ特徴を制作プロンプトにも反映します。作例は技法・指定項目の参考であり、完成画像の人物や構図を固定するためのものではありません。

IDを入力して欄を離れるか読取ボタンを押すと、名前と活動を自動入力します。取得した内容は確認用に表示し、通常は再入力不要。手入力欄は取得内容の修正・IDなしの利用・取得失敗時にだけ開きます。活動の手入力は必須ではありません。読み込んだ活動キーワードも広告・誌面の制作指示に使います。

## VERSION 6（更新履歴・当時の仕様）

空中ポップは６枚ずつ表示し、タップした作例を中央へ出します。コンパクト一覧にも切替可能。比較リセットを選択画面上部に常設。衣装・主役は101選択（従来29＋新規72）になり、追加の各仮装にも固有のオリジナル作例を用意しました。選択変更時は変わらない作例を再構築せず、常時の揺れや光の再描画を削減。短いtransform/opacity演出を全体で強め、最大42個の一時エフェクトに制限しています。

添付は初期設定で「GPTに一度だけ添付」。サイトへキャラ画像を入れる必要はありません。任意で「このツールでまとめる」を選ぶと、キャラ・補助参照・９項目の作例を2560×1800のreference-board.jpgに集約。１画像＋プロンプトの端末共有、JPEG保存、ZIP保存に対応します。共有先の対応は端末・アプリに依存し、自動でChatGPTに画像を挿入する仕様ではありません。

ID読取は名前・自己紹介・見出しに加え、公開記事本文を走査します。取得件数・本文文字数を表示し、確認した話題・イメージ語をプロンプトに反映。「おまかせ」のテーマ・セリフには本文から選んだ原創作の案を使用。明示した選択を優先します。記事本文をそのまま転載せず、有料・会員限定・非公開・R18記事を対象から除外します。既存のauth/CORS/rate limitを維持しています。
