# 無名S note / Halloween Atelier

参加者のキャラ・名前・公開活動を使うHalloween制作プロンプトツール。ブラウザーで利用できます。画像生成は、参照画像・選んだ作例・制作指示をChatGPTに渡して行います。

## 選び方

- **細かく**：全10項目、416の細かな選択肢。元の形式・画風・感情などを維持しています。
- **簡単**：形式・画風・テーマ・文字・サイズの5項目。残りは制作ごとに選びます。
- **おまかせ**：サイズを保ち、3つの組み合わせを提案。選んだ作例の組み合わせで制作します。

366点の個別作例を選択枠と一覧の余白に表示。制作時は、選んだ作例の画像を `selected-style-guide.jpg` にまとめます。顔は参加者の主参照、画風は画風の作例、形式は形式の作例、配色は配色の作例を担当し、他の作例から人物や画風を混ぜないよう指定します。作例の顔や固有の作品をコピーする指示は含めません。

画像付き共有とZIP保存は、キャラ画像・作例画像・prompt.txtを含みます。プロンプトの文字だけをコピーした場合は、画像もChatGPTへ添付してください。生成モデルの解釈、文字の再現、希望寸法には限界があり、プロンプトだけで完全一致を保証するものではありません。

## ページの動き

オレンジのHalloweenイラスト背景、ポップリング、選択の光、パネルと画面の登場演出、灯りの切り替え、選択時の反応、制作準備中の表示。演出ON/OFFとOSの動きを減らす設定に対応。スマホ・タブレット・PC表示を切り替えられます。

## 公開・更新

このフォルダーをGitHub Pagesで公開します。`supabase/functions/halloween-profile/` は専用の公開note情報読取APIです。既存アプリのデータベース・認証・通知機能を使用・変更しません。関数はJWT検証を有効にし、公開クライアントには互換用の公開anonキーだけを使用。サービスキー、Googleアカウント名、旧公開URL、元サイトのGit履歴は移転対象に含めません。

APIは固定されたnote.comの公開プロフィールと直近の無料公開記事本文（最大４件）を取得。画像や入力を保存せず、取得結果は短時間キャッシュします。IDは作品には印字しません。名前と活動は手動編集できます。

```sh
npm run check
npm run preview
```

公開後の閲覧にWorkは不要です。GitHubでのコード更新や一般の開発環境でも管理できます。


## VERSION 5：見比べる一覧とIDからの自動入力

選択肢を画面幅・高さに合わせて4〜12枚ずつ並べるページ式の一覧に変更。分類と検索で絞り込めます。細かな416選択肢、366枚の作例は維持しています。

別ページの作例も最大4枚まで比較に追加して横に並べられます。拡大画面では1〜3倍にして細部を確認でき、そこから正確な選択肢を選べます。画風には固有の見比べるポイント（筆跡、透明感、線、紙・素材など）を表示し、同じ特徴を制作プロンプトにも反映します。作例は技法・指定項目の参考であり、完成画像の人物や構図を固定するためのものではありません。

IDを入力して欄を離れるか読取ボタンを押すと、名前と活動を自動入力します。取得した内容は確認用に表示し、通常は再入力不要。手入力欄は取得内容の修正・IDなしの利用・取得失敗時にだけ開きます。活動の手入力は必須ではありません。読み込んだ活動キーワードも広告・誌面の制作指示に使います。

## VERSION 6

空中ポップは６枚ずつ表示し、タップした作例を中央へ出します。コンパクト一覧にも切替可能。比較リセットを選択画面上部に常設。衣装・主役は101選択（従来29＋新規72）になり、追加の各仮装にも固有のオリジナル作例を用意しました。選択変更時は変わらない作例を再構築せず、常時の揺れや光の再描画を削減。短いtransform/opacity演出を全体で強め、最大42個の一時エフェクトに制限しています。

添付は初期設定で「GPTに一度だけ添付」。サイトへキャラ画像を入れる必要はありません。任意で「このツールでまとめる」を選ぶと、キャラ・補助参照・９項目の作例を2560×1800のreference-board.jpgに集約。１画像＋プロンプトの端末共有、JPEG保存、ZIP保存に対応します。共有先の対応は端末・アプリに依存し、自動でChatGPTに画像を挿入する仕様ではありません。

ID読取は名前・自己紹介・見出しに加え、公開記事本文を走査します。取得件数・本文文字数を表示し、確認した話題・イメージ語をプロンプトに反映。「おまかせ」のテーマ・セリフには本文から選んだ原創作の案を使用。明示した選択を優先します。記事本文をそのまま転載せず、有料・会員限定・非公開・R18記事を対象から除外します。既存のauth/CORS/rate limitを維持しています。
