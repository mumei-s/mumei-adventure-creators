# 無名S note / Halloween Atelier

参加者のキャラ・名前・公開活動を使う制作プロンプトツール。Halloween／普段使いを切り替えてブラウザーで利用できます。画像生成は、参照画像・制作指示をChatGPTに渡して行います。

## 選び方

- **細かく**：全10項目。Halloweenは501の細かな選択肢。元の形式・画風・感情などを維持し、ポーズを独立して指定できます。セリフは「文字・広告・セリフ」の中で選びます。
- **簡単**：形式・画風・テーマ・文字・サイズの5項目。残りは制作ごとに選びます。
- **おまかせ**：サイズを保ち、3つの組み合わせを提案。選んだ作例の組み合わせで制作します。

選択画面の見本は説明用です。生成では項目名と具体的な描画条件を使い、作成者の参照画像から人物や景物の識別要素を保ちます。見本の顔・性別・背景・小道具は生成入力に含めません。

「画像＋プロンプト」は作成者自身の参照画像と `prompt.txt` を共有します。画像は編集後の内容を使い、単一画像では画像バイトをそのまま保存・共有します。複数画像も元の各ファイルを共有でき、別途、参照だけを1枚にまとめて保存できます。ZIPには `reference-` で始まる参照画像と `prompt.txt`、使い方だけを含みます。

「プロンプトのみ」は、必要な主参照をChatGPTで添付して指示と同じメッセージで送ります。人物なしの風景・モチーフは、参照風景や参照配色を明示していなければ添付なしでも制作できます。共有の可否は端末と共有先アプリによります。画像と指示を受け取れない場合はZIP保存または個別コピーで渡します。

- 顔や首の明確な影、髪と衣装の深い暗部、白い逆光、瞳の内部光を具体化。選択配色は維持し、淡色でも光と影の明度差を残します。限定色は指定された色・濃淡へ翻訳します。

- `scripts/check-crystal-anime.mjs` で両モード、配色・人物なし・選択ポーズの保持、旧画風との分離を検査。公開処理にも `npm --prefix halloween run check` を追加しました。

- 画風106種類（102技法と4光表現）の描線・陰影・画材・光学・素材を具体化。少女漫画・少年漫画や服の呼び名だけで主参照の性別・年齢感を変えません。透明水彩、発光アニメ、宝石ホログラムを区別します。
- 通常／Halloweenの選択肢・自動提案・演出を分離。通常は日常・自然・街並みを基本にし、幻想・コスプレは明示選択で使えます。テーマと自動の舞台・衣装・ポーズを揃えます。Halloweenの500選択肢は維持しています。
- 通常に「自然・都市の風景画」、7つの実景テーマ、12の舞台を追加。人物なしでは表情・顔角度・身体ポーズ・人物素材の指示を適用せず、地形・建築・自然光・前中遠景で構図を作ります。明示した人物衣装と風景の組み合わせも使えます。
- 表紙、インタビュー、見開き、新聞の構造を整理。Vogue公式表紙、朝日新聞社公式媒体資料の一面、発行元情報と照合したUNESCO Courierの公開誌面を確認しました。出典と確認範囲は `editorial-reference-sources.js`。実誌画像・人物・ブランド・記事本文は生成へ渡さず、構造だけを制作条件に反映します。
- 新規制作と修正の指示は、画像生成の実行と完成画像そのものの表示を要求します。「画像が出ないときの指示」で生成済み画像の再表示を求められます。サイトがChatGPT側の生成機能や表示を直接制御・保証する機能ではありません。
- 旧履歴は原文を維持し、旧仕様の案内を表示。v11の条件を使う場合は入力画面から新しく制作します。
- 新しい通常風景の見本 `landscape-ordinary-v11.png` はbuilt-in image_genで生成したオリジナルの説明用画像。実在都市の写真ではなく、生成入力にも含めません。制作条件は `ordinary-landscape-artwork-prompt.json`。

`npm run check` は両モード計941件の選択肢出現（共通項目の重複を含む）、47形式、人物なし、技法と配色、明示選択の保持、見本情報の除外、画像返却契約を検査します。クリスタル透光アニメには、両モードのポーズ・配色・人物なしなど202ケースの専用検査もあります。これらは指示とコードの検証で、画像モデルが全選択を常に忠実に実現する保証ではありません。

## ページの動き

オレンジのHalloweenイラスト背景、ポップリング、選択の光、パネルと画面の登場演出、灯りの切り替え、選択時の反応、制作準備中の表示。演出ON/OFFとOSの動きを減らす設定に対応。スマホ・タブレット・PC表示を切り替えられます。

## 公開・更新

このフォルダーをGitHub Pagesで公開します。`supabase/functions/halloween-profile/` は専用の公開note情報読取APIです。既存アプリのデータベース・認証・通知機能を使用・変更しません。関数はJWT検証を有効にし、公開クライアントには互換用の公開anonキーだけを使用。サービスキー、Googleアカウント名、旧公開URL、元サイトのGit履歴は移転対象に含めません。

APIは固定されたnote.comの公開プロフィールと公開記事一覧をページ単位で読み、読める無料公開記事の本文を参照します。有料・会員限定・非公開の本文は取得しません。画像や入力を保存せず、取得結果は短時間キャッシュします。件数・本文文字数は画面に表示しません。IDは作品には印字しません。名前と活動は手動編集できます。

## VERSION 5（更新履歴）：見比べる一覧とIDからの自動入力

選択肢を画面幅・高さに合わせて4〜12枚ずつ並べるページ式の一覧に変更。分類と検索で絞り込めます。細かな416選択肢、366枚の作例は維持しています。

別ページの作例も最大4枚まで比較に追加して横に並べられます。拡大画面では1〜3倍にして細部を確認でき、そこから正確な選択肢を選べます。画風には固有の見比べるポイント（筆跡、透明感、線、紙・素材など）を表示し、同じ特徴を制作プロンプトにも反映します。作例は技法・指定項目の参考であり、完成画像の人物や構図を固定するためのものではありません。

IDを入力して欄を離れるか読取ボタンを押すと、名前と活動を自動入力します。取得した内容は確認用に表示し、通常は再入力不要。手入力欄は取得内容の修正・IDなしの利用・取得失敗時にだけ開きます。活動の手入力は必須ではありません。読み込んだ活動キーワードも広告・誌面の制作指示に使います。

## VERSION 6（更新履歴・当時の仕様）

空中ポップは６枚ずつ表示し、タップした作例を中央へ出します。コンパクト一覧にも切替可能。比較リセットを選択画面上部に常設。衣装・主役は101選択（従来29＋新規72）になり、追加の各仮装にも固有のオリジナル作例を用意しました。選択変更時は変わらない作例を再構築せず、常時の揺れや光の再描画を削減。短いtransform/opacity演出を全体で強め、最大42個の一時エフェクトに制限しています。

添付は初期設定で「GPTに一度だけ添付」。サイトへキャラ画像を入れる必要はありません。任意で「このツールでまとめる」を選ぶと、キャラ・補助参照・９項目の作例を2560×1800のreference-board.jpgに集約。１画像＋プロンプトの端末共有、JPEG保存、ZIP保存に対応します。共有先の対応は端末・アプリに依存し、自動でChatGPTに画像を挿入する仕様ではありません。

ID読取は名前・自己紹介・見出しに加え、公開記事本文を走査します。取得件数・本文文字数を表示し、確認した話題・イメージ語をプロンプトに反映。「おまかせ」のテーマ・セリフには本文から選んだ原創作の案を使用。明示した選択を優先します。記事本文をそのまま転載せず、有料・会員限定・非公開・R18記事を対象から除外します。既存のauth/CORS/rate limitを維持しています。
