# 無名S note / Halloween Atelier

参加者のキャラ・名前・公開活動を使う制作プロンプトツール。Halloween／普段使いを切り替えてブラウザーで利用できます。作画は制作指示と必要な参照画像をChatGPTに渡して行います。本文を持つ複雑な誌面は、確認した主画像をツールに取り込み、組版した完成PNGを表示・保存できます。

## 選び方

- **細かく**：全10項目。Halloweenは503の細かな選択肢。元の形式・画風・感情などを維持し、ポーズを独立して指定できます。セリフは「文字・広告・セリフ」の中で選びます。
- **簡単**：形式・作風・舞台・文字・サイズの5項目。残りは制作ごとに選びます。
- **おまかせ**：サイズを保ち、3つの組み合わせを提案。選んだ項目の組み合わせで制作します。

選択画面の見本は説明用です。生成では項目名と具体的な描画条件を使い、作成者の参照画像から人物や景物の識別要素を保ちます。見本の顔・性別・背景・小道具は生成入力に含めません。

「画像＋プロンプト」は作成者自身の参照画像と `prompt.txt` を共有します。画像は編集後の内容を使い、単一画像では画像バイトをそのまま保存・共有します。複数画像も元の各ファイルを共有でき、別途、参照だけを1枚にまとめて保存できます。ZIPには、ツールへ取り込んだ `reference-` で始まる参照画像、`prompt.txt`、`使い方.txt` を含みます。段階制作の対象では、主画像用の `stage-1-artwork.txt`、画風修正用の `stage-1-style-repair.txt`、誌面組版用の `stage-2-layout.txt` も同梱します。選択画面の見本絵は含みません。

「プロンプトのみ」は、必要な主参照をChatGPTで添付して指示と同じメッセージで送ります。人物なしの風景・モチーフは、参照風景や参照配色を明示していなければ添付なしでも制作できます。共有の可否は端末と共有先アプリによります。画像と指示を受け取れない場合はZIP保存または個別コピーで渡します。

このフォルダーをGitHub Pagesで公開します。`supabase/functions/halloween-profile/` は専用の公開note情報読取APIです。既存アプリのデータベース・認証・通知機能を使用・変更しません。関数はJWT検証を有効にし、公開クライアントには互換用の公開anonキーだけを使用。サービスキー、Googleアカウント名、旧公開URL、元サイトのGit履歴は移転対象に含めません。

APIは固定されたnote.comの公開プロフィールと公開記事一覧をページ単位で読み、読める無料公開記事の本文を参照します。有料・会員限定・非公開の本文は取得しません。画像や入力を保存せず、取得結果は短時間キャッシュします。件数・本文文字数は画面に表示しません。IDは作品には印字しません。名前と活動は手動編集できます。
