# 無名S note / Halloween Atelier

参加者のキャラ・名前・公開活動を使うHalloween制作プロンプトツール。ブラウザーで利用できます。画像生成は、参照画像・選んだ作例・制作指示をChatGPTに渡して行います。

## 選び方

- **細かく**：全10項目、344の細かな選択肢。元の形式・画風・感情などを維持しています。
- **簡単**：形式・画風・テーマ・文字・サイズの5項目。残りは制作ごとに選びます。
- **おまかせ**：サイズを保ち、3つの組み合わせを提案。選んだ作例の組み合わせで制作します。

294点の個別作例を選択枠と一覧の余白に表示。制作時は、選んだ作例の画像を `selected-style-guide.jpg` にまとめます。顔は参加者の主参照、画風は画風の作例、形式は形式の作例、配色は配色の作例を担当し、他の作例から人物や画風を混ぜないよう指定します。作例の顔や固有の作品をコピーする指示は含めません。

画像付き共有とZIP保存は、キャラ画像・作例画像・prompt.txtを含みます。プロンプトの文字だけをコピーした場合は、画像もChatGPTへ添付してください。生成モデルの解釈、文字の再現、希望寸法には限界があり、プロンプトだけで完全一致を保証するものではありません。

## ページの動き

オレンジのHalloweenイラスト背景、揺れる作例カード、灯りの切り替え、選択時の反応、制作準備中の表示。演出ON/OFFとOSの動きを減らす設定に対応。スマホ・タブレット・PC表示を切り替えられます。

## 公開・更新

このフォルダーをGitHub Pagesで公開します。`supabase/functions/halloween-profile/` は専用の公開note情報読取APIです。既存アプリのデータベース・認証・通知機能を使用・変更しません。関数はJWT検証を有効にし、公開クライアントには互換用の公開anonキーだけを使用。サービスキー、Googleアカウント名、旧公開URL、元サイトのGit履歴は移転対象に含めません。

APIは固定されたnote.comの公開プロフィール・公開記事見出しだけを取得。画像や入力を保存せず、取得結果は短時間キャッシュします。IDは作品には印字しません。名前と活動は手動編集できます。

```sh
npm run check
npm run preview
```

公開後の閲覧にWorkは不要です。GitHubでのコード更新や一般の開発環境でも管理できます。
